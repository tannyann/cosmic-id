## 0. 結論(先に読む3分)

1. **裏の顔は、もう8割できている。** Museum(19体系の来歴・批判・文献)、Skeptic Mode(査読研究に基づく批判注記)、深層チャプター、Star Map、What if、10年タイムライン——「深く考察できる世界」の資産はすでにリポジトリにある。**[事実: `src/museum-ui.js` / `src/skeptic.js` / `src/deepChapters.js` ほかを実読]**
2. **足りないのは表の顔ただ一つ、「質問に答える体験」と「名乗れる名前」。** 現在の入口は「名前+生年月日 → 19体系が一気に出る」。MBTIの快感の中心である *質問に答える過程* と *3文字で名乗れるラベル* が**存在しない**。**[事実: `index.html` のフォームは name / name-roman / birthdate のみ]**
3. **推奨案は「表12 × 裏12 = 144通りの二層ID」。** 表=12問の質問で決まる「見せている顔」、裏=生年月日から算出される「生まれ持った質」。**両者を同じ12の語彙で出すことで、"ズレ"そのものが最大のコンテンツになる**(他人から見える自分 vs 内側の自分)。既存の西洋占星術構造(4エレメント × 3クオリティ = 12)をそのまま使えるので、模倣にならず、実装も既存計算の再利用で済む。
4. **哲学は説教ではなく機能で届ける。** 「性格は固定されたものなのか」は文章で語るのではなく、**再診断でIDが書き換わる**という体験で示す。倫理(結果を絶対視させない)と継続率(再訪動機)が同じ設計で両立する。
5. **法務の要注意点が1つある。** 「MBTI」は日本で商標登録済みで、日本MBTI協会が無断使用に対し商標権侵害(損害賠償・刑事罰)を明記して警告している。**[事実: [日本MBTI協会 公式](https://www.mbti.or.jp/attention/)]** → マーケ文言・OGP・コード内の識別子で `MBTI` / `16Personalities` / `INFP` 等の4文字コードを**一切使わない**方針を最初から徹底する。
6. **シェアカードに生年月日を焼き込んでいる現状は、10代ユーザーを迎える前に見直したい。** **[事実: `src/share.js` の `drawShareDate()` が `YYYY · MM · DD` を描画]** 依頼範囲外のため修正はしていない。§11 に詳細。

**決めてほしいこと(詳細は §12)**: ①タイプ数と体系(12案を推奨) ②ビジュアル路線(既存の黒×金を継承 or かわいい寄せ or 色を選ばせる) ③入口の順序(質問先行 or 生年月日先行) ④裏の顔を無料にするか。

## 2. 調査:MBTIはなぜ日本で流行したか

> 注記: 数値データについて。「Z世代の◯%が診断済み」といった具体的な比率が多数のブログ記事で流通しているが、**今回のWeb調査では一次調査(調査主体・n数・実施時期が明示されたもの)まで遡れなかった** → **[未確認]**。以下では比率を根拠として使わず、**経路と構造**の分析に絞る。SHIBUYA109 lab. のような一次調査機関がZ世代女性を継続調査していること自体は確認できた **[事実]**。

### 2-1. 経路 **[事実に近い / 複数の日本語メディアが一致して記述]**

1. **韓国が震源。** 2021年頃から韓国で日常語化。K-POPアイドルが自分のタイプを公表 → YouTube/バラエティで「MBTIリアクション」「タイプ別あるある」が量産され、自己紹介の定番になった。
2. **コロナ禍の在宅 × 無料オンライン診断**が土壌になった。
3. **日本へは韓国コンテンツ経由で流入し、2023年頃からZ世代中心に定着。**
4. **流行している「MBTI」の実体は、無料Web診断の 16Personalities である。** 公式MBTIは有資格者による有料実施が前提で、質問も結果の出し方も別物 **[事実: 日本MBTI協会が公式に「全くの別もの」と明言]**。

出典: [日本MBTI協会「16Personalities性格診断テストを『MBTI®』だと思って受けられた方へ」](https://www.mbti.or.jp/attention/) / [J-CAST「MBTIは話題の性格診断16Personalitiesと『全くの別物』」](https://www.j-cast.com/2023/07/03464452.html?p=all) / [東洋経済オンライン「Z世代が『MBTI』の次にハマる"超細分化"診断の正体」](https://toyokeizai.net/articles/-/935044) / [SHIBUYA109 lab. 関連調査](https://canvas.d2cr.co.jp/ztomo-mbti/)

### 2-2. なぜ受けたのか(構造分析) **[仮説: 観察された事象からの構造化。実証データではない]**

**A. 自己紹介の圧縮**
- 4文字は**発話コスト最小**。「INFPです」で自己紹介が1秒で終わる。プロフィール欄・マッチングアプリ・大学の新歓に収まる。
- → 設計への含意: **タイプ名は3〜6文字で言い切れること**。これは可愛さよりも先に来る要件。

**B. 16という数の絶妙さ**
- 12星座より多く「私だけ感」があり、64タイプより少なく「覚えられる/仲間に会える」。
- 平均6.25%は「教室に2人はいる」密度。**孤立しない程度に希少**。
- → 含意: **12〜16が最適域**。COSMIC IDは12を推奨(§5)。

**C. 分解可能性(これが血液型4分類との決定的な差)**
- 「Iだけど社交的」「私はほぼ50%のTF」——**軸が4本あるから会話が続く**。単一ラベルは会話が1往復で終わる。
- → 含意: 単一タイプ名 + **軸スコアの併記**が効く。

**D. 肯定的記述とバーナム効果**
- 弱点も「愛おしい欠点」として書かれ、否定されない。曖昧で一般的な記述を自分専用と感じる心理(バーナム効果)が働く **[事実: 心理学で確立した効果。MBTIの再検査信頼性への学術的批判も存在]**。
- → 含意: COSMIC IDの既存トーン(断定しない/ネガティブは変容方向で書く)は**この点でMBTIより強い**。

**E. 二者関係の生成器**
- 相性、あるある、「◯◯型の彼氏」——**組み合わせの数だけUGCが生まれる**。16×16=256通りのネタが自動供給される。
- → 含意: 表12×裏12=144、対人相性は12×12=144。**ネタの井戸は十分深い**。

**F. 説明責任の外部化(安心)**
- 「私がこうなのはINFPだから」。自分を責めずに自分を説明できる。**分類は免罪符として機能する。**
- → 含意: ここが倫理の分岐点。免罪符は救いにもなるが、固定観念にもなる(§11)。

**G. 韓国文化資本による権威づけ**
- 「推しと同じタイプ」が価値を持つ。占い(スピリチュアル)より"心理テスト"のほうが**知的に見える**ことも効いた[推測]。

**H. 日本側の下地**
- 血液型性格分類の長い受容史、星座・干支が日常語彙であること、「診断メーカー」文化。**日本人は元々"分類されて名乗る"ことに慣れている**[仮説]。COSMIC IDにとって追い風。

### 2-3. 逆風も見えている **[仮説]**

2024〜25年にかけて「MBTIで人を判断するな」「MBTIハラスメント」という批判言説が可視化している。**"決めつけない診断" は今から入るサービスにとって差別化の旗になる**——これはCOSMIC IDの既存思想(「あなたの物語はあなたが書く」)とそのまま一致する。

## 4. コンセプト:表の顔と裏の顔

### 4-1. 中核メタファー ——「IDは発行される。では、誰が発行したのか?」

プロダクト名 COSMIC ID の "ID" は**身分証**。身分証とは、社会が個人を分類し、識別するために発行する装置である。

- **表の顔** = 発行されたID。名前・シンボル・色・称号があり、人に見せられる。
- **裏の顔** = そのIDを**誰が、何を根拠に発行したのか**という問い。

この一本の線で、依頼書が挙げた哲学テーマが全部つながる:

| 依頼書のテーマ | 体験としての置き換え |
|---|---|
| 自分とは何か | 表IDと裏IDが**食い違う**という事実に出会う |
| 他者から見える自分と内面の自分 | 表=質問に自分で答えた顔 / 裏=生年月日という**自分で選べなかった** データからの顔 |
| 性格は固定されたものなのか | **再診断でIDが書き換わる**。更新履歴が残る |
| 人間を分類することの意味と限界 | Skeptic Mode / Museum(既存資産) |
| 個人と社会の関係 | IDという語そのもの。「発行元は誰か」 |
| COSMIC ID世界における自分の位置 | 12の系(エレメント×クオリティ)に属し、他の系との関係を持つ |

### 4-2. 二層の設計

```
┌─ 表の顔 ─────────────────┐   軽い・速い・かわいい・名乗れる
│ 12問(60秒) → タイプ1つ    │   共有される / 会話に持ち出せる
│ 称号・シンボル・色・1行     │   ここだけで完結してもよい
└──────────────────────────┘
              ↓  「このIDには、まだ発行されていない面があります」
┌─ 裏の顔 ─────────────────┐   重い・深い・静か・語れない
│ 生年月日 → 19体系の縮約     │   ズレの解説 / Museum / Skeptic
│ 表とのズレ / 更新される履歴  │   ここに来た人だけが見る
└──────────────────────────┘
```

**設計原則: 裏は"報酬"ではなく"招待"。** 「課金しないと本当の自分が分からない」は絶対に作らない(§11)。裏へ行くコストは、お金ではなく**時間と内省**。

### 4-3. ビジュアル上の緊張とその解き方

「10代後半〜20代女性が気軽に」と「黒×金の神秘・高級」は、放っておくと衝突する。3つの解き方:

- **解法A(推奨): 入口だけ明度を上げる。** 質問画面と結果カードは、既存パレットの `--gold-champagne #f5ecd4` / `--accent-rose #c97a9a` / `--accent-purple #a67fd8` を**主役に昇格**させ、背景の黒を「深い藍〜すみれ」に寄せる。書体は明朝のまま。**新色を足さずに"軽さ"を作る**ので、ブランドは壊れない。
- **解法B: シェアカードの色をユーザーに選ばせる。** 3つのカラーウェイ(§10)。自分で選んだカードは共有率が上がる[仮説]。世界観は保ったまま「かわいい」の選択肢を与えられる。
- **解法C(非推奨): かわいい系に全面転換。** P2/P3を失い、既存の最大の資産(誠実さと重厚さ)を捨てることになる。

## 5. 独自診断システムの案

### 5-1. 前提となる制約(全案共通)

1. **`MBTI` / `16Personalities` / `INFP` 等の4文字コードを使わない**(商標・混同回避。§11)
2. 質問文は既存診断からの翻案をしない(**自前で書き下ろす**)
3. 結果は既存トーン規範に従う(断定しない/ネガティブは変容方向)
4. 計算は純粋関数、文言は i18n locales、描画は ui —— `AGENTS.md` の分離を守る

### 5-2. 案A(推奨)「二層ID型」——表12 × 裏12 = 144通り

**構造: 4エレメント(火・地・風・水) × 3クオリティ(拓く・保つ・変える) = 12。** 西洋占星術の12星座がまさにこの構造で作られており、**COSMIC IDの世界観に元から内蔵されている軸**を使うことになる(模倣ではなく、自分の体系からの導出)。

- **表の顔** = 12問の質問に本人が答えて決まる。「あなたが見せている顔」
- **裏の顔** = 生年月日から算出(太陽星座のエレメント + 九星/五行 + ライフパスの合成)。「生まれ持った質」
- **同じ12の語彙で出す**ので、一致/ズレが即座に意味を持つ:
  - 一致 → 「あなたは、自分の見せ方と生まれ持った質が重なっている稀な人」
  - ズレ → 「外に出している火と、内側の水。その落差があなたの体力を使っているのかもしれません」

たたき台の12タイプ(名称は仮。既存 `LOVE_ARCHETYPES` と語彙が重複しないよう別系統で命名):

| | 拓く(始動) | 保つ(維持) | 変える(適応) |
|---|---|---|---|
| **火** | 焔の先駆 ⟡ | 灯火の番人 ⟠ | 野火の戯れ ⟢ |
| **地** | 礎の開拓 ⬖ | 石の器 ⬗ | 苗床の手 ⬘ |
| **風** | 初風の使い ✧ | 星読みの席 ✦ | 羽音の旅 ✩ |
| **水** | 泉の湧き ◈ | 潮の護り ◇ | 霧の語り ◆ |

**名乗り**: 「野火(のび)」「潮護(しおまもり)」のように**2〜4文字で言える略称**を必ず持たせる(§2-2 A)。英語版は "Wildfire" "Tidekeeper" のような1語。

**軸スコアも併記**する(§2-2 C): 火/地/風/水の4本を%で、クオリティを3本で。「私、火80%だけど水も30%ある」が会話になる。

- 魅力 ★★★★★(ズレという他社にない発見がある)
- 拡散性 ★★★★☆(名乗れる + 比較できる + カード映え)
- 実装難易度 ★★☆☆☆(質問と辞書が主。裏は既存計算の合成)
- 継続率 ★★★★☆(再診断でIDが変わる)
- 独自性 ★★★★★

### 5-6. 推奨案とその理由

> **案A(表12 × 裏12)を軸に、案Bを結果画面の表現として、案C/Gを裏への進み方として組み合わせる。**

理由:
1. **12はCOSMIC IDの母語である。** 12星座・十二支・12ヶ月・既存の12恋愛アーキタイプ。4×3=12は借り物ではなく自分の体系からの導出になる。MBTI模倣批判も商標リスクも回避できる。
2. **「ズレ」は他社が構造的に真似できない。** 質問型診断(16Personalities系)は生年月日を持たず、占いアプリは質問を持たない。**両方を持っているのはCOSMIC IDだけ**。
3. **実装が軽い。** 裏の顔は既存の `calculations.js` の出力を合成するだけで、新しい占術計算を書かなくてよい。
4. **哲学が機能に翻訳できる。** 「他者から見える自分と内面の自分」を、説明ではなく**2枚のカードの差**として提示できる。
5. **既存ユーザー体験を壊さない。** 19体系はそのまま「裏の顔の詳細」として下層に残る。

### 9-2. カードに載せる情報の優先順位

1. **称号(タイプ名)** — 最大サイズ。これが「一目で分かる」の本体
2. **シンボル + 色** — 遠目でもタイプが識別できる
3. **キャッチ1行**(15字以内) — 例:「静かに燃えつづける火」
4. **「これ自分っぽい」3語**(体言止め) — 例:「即断 / 熱量 / 一点集中」
5. 4軸のミニスコア(小さく)
6. サービス名 + URL(小さく、しかし必ず)
7. ユーザー名 — **任意。既定はOFF**
8. **生年月日 — 載せない**(現行メインカードは載せている。§11)

### 9-3. 媒体別の最適化

| 媒体 | サイズ | 注意 |
|---|---|---|
| Instagram ストーリー | 1080×1920 | **上約250px / 下約310pxはUIに隠れる**。主要情報を中央60%に収める |
| Instagram 投稿 | 1080×1350 | 4:5。フィードで最も面積が取れる |
| X | 1200×675 | 横長。**縦カードをそのまま出すと両端が切れる**ので横版が要る |
| TikTok | 1080×1920 | 静止画共有は弱い。**画面録画される前提**で、Web上の発行演出を作り込むほうが効く[仮説] |
| LINE | 1080×1350 | テキスト + 画像。友達の1:1共有が主戦場 |

### 9-4. 拡散されやすくする文言・UIの工夫

- カードに**問いを1行入れる**:「あなたの裏の顔は?」——見た人が自分でも試したくなる(広告としての二重役割)
- コピー用テキストを自動生成:`私のCOSMIC IDは【野火の戯れ】でした。/ 静かに燃えつづける火 / あなたのIDは? → URL`
- **保存よりシェアを一等地に**置く(現状は Instagram / 保存 の2ボタン。順序は正しい)
- スクショ前提のUI: 結果画面そのものを、切り取っても成立する構図にする
- 「友達と比べる」ボタンをカードの直後に置く(比較は最強の再拡散動線[仮説])

### 9-5. 将来の動きのある演出

- 発行演出: カードが裏から返る / 星が集まって称号になる(CSS + Canvas。**MVPでもここだけは作り込む価値がある**)
