# CURSOR-BRIEFS.md — Cursor への委任ブリーフ集

Cursor で cosmic_id を開くと `.cursor/rules/` の規約(関心の分離・禁則・トーン)が自動で効く。
以下の各ブリーフを **Cursor のチャットにそのまま貼り付けて**使う。1ブリーフ=1ブランチ=1PR。
検収の基準と担当は `docs/ISSUES.md`(I-12 / I-14)。

---

## ブリーフ A: 375px モバイル崩れの監査と修正(I-12)

```
このプロジェクトはスマホユーザーが中心です。幅375px(iPhone SE相当)でのレイアウト崩れを
洗い出して styles.css 中心に修正してください。

手順:
1. npm run build && npm run preview で本番ビルドを起動し、DevTools で 375px 幅にする
2. 全主要画面を点検: 入力フォーム / サマリー / カード一覧 / 深掘りモーダル /
   相性・ラブ・タイムライン・ミュージアム等の各 -ui モジュール / シェアカード
3. 崩れ(横スクロール発生・要素はみ出し・文字重なり・タップ領域44px未満)を
   リスト化してから、styles.css を修正する。構造変更が必要な場合のみ index.html → ui.js の順

制約:
- CSSフレームワーク導入・全面リファクタ・デザイン刷新は禁止。既存のCSS変数(配色管理)を維持
- .premium-section.unlocked と isPremiumDemo の関係(プレミアムぼかしロック)を壊さない
- 修正前に「崩れ箇所リスト(画面名+症状)」を先に出すこと。修正はその後

完了条件: 375pxで全主要画面に横スクロールが出ない。修正した箇所の before/after を報告
```

## ブリーフ B: デザインポリッシュ(I-14)

```
既存のデザイン方向(神秘的・ダーク基調・CSS変数による配色管理)を維持したまま、
仕上がりの質感を上げてください。方向性の変更は不可、磨き込みのみです。

対象(優先順):
1. タイポグラフィ: 見出し/本文のサイズ・行間・字間の一貫性(rem基準)。日本語と英語の両方で確認
2. 余白のリズム: カード内・カード間・セクション間のスペーシングを一定の刻みに揃える
3. モーダル: 開閉アニメーションの滑らかさ、スクロール時のヘッダー挙動、閉じるボタンのタップ領域
4. フォーカス/ホバー状態: キーボード操作時の視認性(アクセシビリティ)
5. カードのホバー・タップのフィードバック(transform/shadow は控えめに)

制約:
- 変更は styles.css に閉じる(どうしても必要な場合のみ index.html のクラス付与まで)
- 色は既存のCSS変数の値を使う。新しい色を増やさない
- フォントの追加読み込み(Webフォント追加)はしない
- 派手なアニメーション・パララックス等の追加は禁止

完了条件: 変更点を「対象/変更内容/理由」の表で報告。1440px と 375px の両方で確認済みであること
```

## ブリーフ C: 文言の微修正をするとき(汎用・小粒用)

```
文言を変更します。以下を厳守してください:
- 文言の実体は src/i18n/locales/ja/ と src/i18n/locales/en/ にある。両方を必ず同期する
  (キー構造を一致させる。片方だけの変更は不可)
- トーン: 断定しない(「必ず〜します」→「〜とされます」)。ネガティブ断定・医療/法律/財務助言は禁止
- content.js(ルートの src/content.js)は旧構成の名残なので、i18n 配下を正とする
- 変更後、npm run dev で ja/en 両方の表示を確認する

変更内容: (ここに具体的な変更を書く)
```
