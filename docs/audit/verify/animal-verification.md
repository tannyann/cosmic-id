**目的**: 実装の動物占い(`animalUranai` / `animalGroupIndex`)が、個性心理學(動物占い®)の公式判定とどこまで一致/不一致かを、出典付きで確定する。I-1決定「独自12分類と明記」の注記の正確さを裏付ける。

## 0. 実装の式(現状)

`src/calculations.js`:

```js
export function animalUranai(year, month, day) {
  const ref = new Date(Date.UTC(1925, 3, 23));   // 1925-04-23 起点
  const birth = new Date(Date.UTC(year, month - 1, day));
  const days = Math.floor((birth - ref) / 86400000);
  const num = ((days % 60) + 60) % 60 + 1;        // 1..60 の通し番号
  const idx = (num - 1) % 12;                      // 60→12縮約
  return { num, name: ANIMAL_NAMES[idx] };
}
export function animalGroupIndex(animalIdx) {
  return animalIdx % 3;                            // 月0 / 地1 / 太陽2
}
```

`ANIMAL_NAMES`(`src/i18n/locales/ja/content.js`、idx 0..11):
`狼, こじか, 猿, チータ, 黒ひょう, ライオン, 虎, たぬき, 子守熊, ゾウ, ひつじ, ペガサス`

グループは `idx % 3` → idx0狼=月, idx1こじか=地, idx2猿=太陽, idx3チータ=月 …(配列順の単純ローテーション)。

## 1. 動物占い(個性心理學)の公式計算方法

流通している公式互換の計算方法(複数サイト一致):

1. **生年月一覧表(基数表)** で「生まれた年 × 生まれた月」の交差数字(基数)を引く。
2. 基数 + 生まれた日 = 合計。**合計が61以上なら −60**。→ これが **1〜60 のキャラNo.**。
3. No. に対応する **60分類キャラ**(= 12動物 × 5カラー)を表から引く。

出典: [占いPicks](https://fortune-telling.life/animal/diagnosis/)、[Spicomi 早見表](https://spicomi.net/articles/1125)、[TJF 教材PDF(動物占い®クレジット付き)](https://www.tjf.or.jp/hidamari/pdf/34_furoku.pdf)、[動物占い®公式サイト](https://www.doubutsu-uranai.com/)。

### 1.1 基数表を使わない等価計算式(Excel、検証済み)

[外部照合] [だいのメモ](https://dai-memo.com/422/) が公開する等価式:

```
キャラNo. = ((Excelシリアル値 + 8) MOD 60) + 1
```

Excelシリアル値 = 1900年日付システム(1899-12-30 を 0 とする経過日数)。
この式を node で実装し、公開されている「手計算の worked example」2件で**検証済み**(下記)。基数表を引く手順と完全に一致する。

| 検証ケース | 期待(出典の手計算) | 本式の算出 | 判定 |
|---|---|---|---|
| 1980-03-10 | No.19 | 19 | ✓一致 |
| 1980-06-27 | 基数41+27=68→68−60=No.8 | 8 | ✓一致 |

worked example 出典: [占いPicks](https://fortune-telling.life/animal/diagnosis/)(1980-03-10=19「さすらいの狼」/ 1980-06-27=基数41)。

### 1.2 番号→動物の対応(60分類の並び順・独立2ソースで一致確認した範囲)

No.1 は **チータ**(狼ではない)。No.51=ライオン。番号順に 12動物が「狼→こじか→…」と単純循環する**のではなく**、不規則に並ぶ。
下記5件で必要な番号(10/17/29/30/60)は独立2ソース([占いPicks/uranai-deep](https://uranai-deep.com/dobutsuranai-hayamihyo/) と [サチ活](https://sachikatsu.love/60-classification-characters/))が**完全一致**:

| No. | 10 | 17 | 29 | 30 | 60 |
|---|---|---|---|---|---|
| 公式動物 | 子守熊 | こじか | ひつじ | 狼 | 虎 |

（中間帯 No.19〜28 の一部は2ソースで読み取り差があり[未確認]。ただし本照合の5件はいずれも一致帯に収まる。）

## 2. 実装 vs 公式 照合表(誕生日5件)

実装値は node 実行(§0)、公式No.は§1.1の検証済み式、公式動物は§1.2の対応表。

| 誕生日 | 実装No.(num) | 実装動物 | 公式No. | 公式動物 | 動物一致? |
|---|---|---|---|---|---|
| 1990-05-15 | 4 | チータ | 17 | こじか | ✗ |
| 1980-01-01 | 57 | 子守熊 | 10 | 子守熊 | ○(偶然一致) |
| 2000-12-31 | 47 | ひつじ | 60 | 虎 | ✗ |
| 1975-06-15 | 16 | チータ | 29 | ひつじ | ✗ |
| 1995-03-03 | 17 | 黒ひょう | 30 | 狼 | ✗ |

**照合5件中、動物が一致したのは1件のみ(それも偶然)。4件が不一致。**
実装の動物占いは公式(個性心理學)と**非互換**と確定。

## 3. 起点位相・60→12縮約・グループ分けの正否

### 3.1 起点(1925-04-23 = num1)→ ✗ 位相が13ズレている

実装の No.(num)と §1.1 検証済み式の公式No.は、5件すべてで **一定の差 +13**(mod 60)。

| 誕生日 | 実装No. | 公式No. | 差(mod60) |
|---|---|---|---|
| 1990-05-15 | 4 | 17 | 13 |
| 1980-01-01 | 57 | 10 | 13 |
| 2000-12-31 | 47 | 60 | 13 |
| 1975-06-15 | 16 | 29 | 13 |
| 1995-03-03 | 17 | 30 | 13 |

差が全件一定 = 実装の60日サイクル(六十干支)の**進み方は公式と同型だが、起点の位相が13日ぶんズレている**。実装の起点 1925-04-23 での公式No.は **14**(1 ではない)。
→ 枠組み(連続60サイクル)は正しいが、**起点は誤り**。位相を13戻す(または起点を13日ずらす)と番号自体は公式一致する。

### 3.2 60→12縮約 `(num-1)%12` → ✗ 別物

公式は No.→動物が **12おきの単純循環ではない**(§1.2、No.1=チータで狼始まりですらない)。実装の `(num-1)%12` は ANIMAL_NAMES の並び順に依存した**独自マッピング**。
仮に §3.1 の位相を直して No. を公式一致させても、この縮約式のままでは動物は合わない(公式は不規則配列)。**60→12は対応表への置換が必須**。

### 3.3 グループ分け `idx%3`(Moon0/Earth1/Sun2)→ ✗ ラベル不一致(12中10件)

実装ラベル(`cardInteractives.js` renderAnimalGroup: index 0=Moon,1=Earth,2=Sun)vs 公式3分類([外部照合] [hbn-office 基本3分類](https://www.hbn-office.com/isd/what02.html)、[らる note](https://note.com/raru3105/n/nb234144ac5f9) で ひつじ=MOON と整合)。

公式:
- **MOON**: こじか・たぬき・ひつじ・黒ひょう
- **EARTH**: 狼・猿・虎・子守熊
- **SUN**: ゾウ・チータ・ペガサス・ライオン

| 動物 | 実装 idx%3 ラベル | 公式 | 一致 |
|---|---|---|---|
| 狼 | Moon | EARTH | ✗ |
| こじか | Earth | MOON | ✗ |
| 猿 | Sun | EARTH | ✗ |
| チータ | Moon | SUN | ✗ |
| 黒ひょう | Earth | MOON | ✗ |
| ライオン | Sun | SUN | ○ |
| 虎 | Moon | EARTH | ✗ |
| たぬき | Earth | MOON | ✗ |
| 子守熊 | Sun | EARTH | ✗ |
| ゾウ | Moon | SUN | ✗ |
| ひつじ | Earth | MOON | ✗ |
| ペガサス | Sun | SUN | ○ |

ラベル一致は 2/12(ライオン・ペガサスのみ)。
参考: 実装の **Earth群(idx%3==1)の集合 {こじか・黒ひょう・たぬき・ひつじ} は公式 MOON 集合と完全一致**しているが、ラベルが「Earth」で付いており、残り2群(Moon/Sun)は公式 EARTH/SUN が半々に混ざる。→ グループ分けも公式非互換。

## 4. 商標・公式コンテンツ転載の注意

- **「動物占い®」は登録商標**(個性心理學研究所/株式会社ノア・弦本將裕氏。1997年発表)。出典: [個性心理學研究所](https://www.noa-group.co.jp/koseisinri/)。
- 転載NG: 公式の **60キャラの固有名称**(例「長距離ランナーのチータ」等の形容付きネーミング)、キャラ解釈文、公式画像。これらは同研究所の著作物。
- OK/グレーの分離: **計算方式(六十干支ベースの60サイクル)自体は四柱推命由来の一般手法**で流通しており、方式の互換化は可能。ただし本アプリは商標・キャラ名を避け、**「独自の簡易12分類」と明記**する I-1 方針が最も安全。動物名12種(狼・こじか等)は一般名詞だが、"動物占い®"の名称・世界観を想起させる表示は避けること。

## 5. 結論

**実装の動物占いは個性心理學(動物占い®)と非互換。** 3つの層すべてでズレを確認:

1. **起点(位相)**: 六十干支サイクルの枠組みは正しいが、起点が **13日ぶんズレ**(1925-04-23 の公式No.は14)。番号自体が公式と不一致。[確定]
2. **60→12縮約**: `(num-1)%12` は独自配列マッピング。公式の不規則な60分類表とは別物。位相を直しても動物は合わない。[確定]
3. **グループ(月/地/太陽)**: `idx%3` のラベルは公式3分類と 12中10件で不一致。[確定]

**照合5件中、動物が一致したのは1件(1980-01-01=子守熊)のみで、それも偶然**(No.は57 vs 10 で不一致)。

→ I-1 の「独自12分類と明記」方針は妥当。本アプリの動物占いは公式判定と一致しないため、公式互換を謳わず「独自の簡易分類」と注記するのが正確かつ安全。
