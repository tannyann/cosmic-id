### うるう日(2/29)スキップの確認

- 公式ドリームスペル/13の月の暦は **2/29 を「KINを持たない日(Hunab Ku 0.0 / Day-out-of-Time系の扱い)」としてスキップ**する。13moon系calculatorの説明に「the system counts days from the start date, **excluding leap days (February 29)**」と明記。→ **ルール有り(実装は未対応=誤り)。**
- 実測の裏取り: 実装は 2020-02-28→KIN101、2020-03-01→KIN103 と **+2**。2/29 を KIN を持つ1日として数えている。公式(2/29スキップ)なら +1。
