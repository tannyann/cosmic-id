## 目的（なぜ）

COSMIC ID は19体系を横断解釈するが、README 自身が「流派によって結果が変わる」占術を弱点として告白している。
本格サービス化の前に、**どの体系がどの流派とどうズレるか**を体系ごとに棚卸ししたい。
あなたの成果物は、「どの式を正とするか」という経営判断を下すための材料になる。

## 最初に読む（これがあなたの脳）

- `AGENTS.md` — 「占術の流派論争に巻き込まれそうな修正は○○流と明記」の方針、断定禁止トーン
- `README.md` の「計算の正確性について」— 既知の弱点（下記）
- `src/calculations.js` — 実装されている式の実体

## 難易度（上限で取り組む）

これは「唯一の正解が存在しない」最難クラスの問題だ。流派が割れている領域を、断定せず・網羅的に整理する。自分の能力の上限のつもりでやる。

## 調べる対象（README が挙げる要注意領域）

1. **九星気学** — 立春(2/4固定)切替の簡易版。毎年の立春**時刻**まで見る流派との差。
2. **動物占い(個性心理学)** — `1925-04-23` 起点の60日サイクル簡易版と、公式60分類との差異。
3. **マヤ暦 KIN** — ホセ・アグエイアス暦、`2013-07-26 = KIN33` 起点の妥当性。
4. **月星座** — 出生時刻が要るため現状「月相からの傾向」のみ。代替の妥当性。
5. その他 `calculations.js` を読んで、流派差が出そうな体系があれば追加。

## やること（分身に振る）

- 体系ごとに**独立したサブエージェント**を立て、並行で調査させる。各サブは「主要な流派」「本実装が採る式」「具体的にどの入力でズレるか(実例日付)」を出す。
- 各サブの結論を1つのレポート `docs/audit/fortune-accuracy.md` に集約。
- 最後に、**まっさらな別の分身**に「レポートの主張が `calculations.js` の実装と実際に一致するか」をコード実行込みで検証させる。

## 止まる条件（重要）

**どの流派を正とするかは決めない。** それは方針判断なのでこちらに委ねる。選択肢と各流派のメリット・デメリットを「おすすめ付き」で提示するところまでで止まる。コードの式そのものはこのコマンドでは変更しない（調査と検証のみ）。

## 報告（結論から）

まず TLDR：「最もズレが大きい体系はどれか」から書く。
- WebSearch で得た主張は出典を併記。確認しきれないものは「未確認」と明記。
- 各体系は「現状の式 / 主要流派 / ズレる実例 / 推奨対応(候補)」の表で。
- 学びは `docs/learnings/` に 1件1ファイルで蓄積（重複を作らない、誤りは消す）。
